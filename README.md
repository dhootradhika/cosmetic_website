# 💄 Cosmetic Website

## 📌 Project Overview

This project is a **Cosmetic Website** developed to showcase beauty and skincare products in a clean and user-friendly interface. The website provides an engaging UI for browsing products and demonstrates front-end (and optionally back-end) development skills.

---

## ✨ Features

* 🛍️ Product listing page for cosmetics
* 🎨 Attractive and responsive UI design
* 📱 Mobile-friendly layout
* 🔍 Easy navigation with header and footer
* 🖼️ Product images and descriptions
* 🧾 (Optional) Cart / login functionality

---

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* (Optional) PHP
* (Optional) MySQL

---

## 🚀 How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Run `index.html` in your browser
